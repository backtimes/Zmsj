网关问题合集

网关问题合集

1. 首要

在进行任何网关维护或故障排查之前，首先确认以下首要事项：

1.1 网关升级

升级网关前，请确认当前版本号，确保有可用的升级包。升级过程中请勿断电或断网，升级完成后需要验证服务是否正常启动。

提示：升级前建议备份当前配置文件和重要数据。

1.2 网关重启

重启网关前，请确保所有正在进行的关键任务已完成。重启命令因系统不同而异：

# Linux系统
sudo reboot

# Windows系统
shutdown /r /t 0

2. 黑色设备(Debian)

黑色设备采用Debian Linux操作系统，主要用于视频网关服务部署。

2.1 产品

黑色设备为标准视频网关硬件设备，搭载Debian Linux系统，预装视频网关服务软件。

2.2 连接

使用XShell等SSH工具连接Linux设备。连接时需要设备的IP地址、用户名和密码。

2.3 网页查看

通过浏览器访问设备的Web管理界面，可以查看设备状态、配置网络参数和管理服务。

默认Web管理地址为设备的IP地址，端口通常为80或8080。

2.4 U盘插入设备

将U盘插入设备的USB接口后，Debian系统通常会自动挂载。若未自动挂载，需手动执行挂载操作：

# 查看U盘设备
fdisk -l

# 创建挂载点并挂载
sudo mkdir -p /mnt/usb
sudo mount /dev/sdb1 /mnt/usb

2.5 系统进入命令行

当设备连接了显示器和键盘时，可以直接进入命令行界面。若需要通过SSH远程连接，请使用XShell、Putty等工具。

2.6 清理内存

当设备存储空间不足时，需要清理日志文件和临时文件以释放空间。

清理日志文件命令：

sudo rm -rf /var/log/daemon.log && sudo rm -rf /var/log/syslog && sudo service rsyslog stop && sudo systemctl disable rsyslog

清理完成后重启设备：

sudo reboot
如果挂载点已满，可以删除崩溃报告目录：
# 查看磁盘使用情况
df -h
df -i

# 删除崩溃报告
rm -rf /usr/local/sppvcell/plugins/DVM1G10504/CrashReport/

2.7 黑色debian升级

升级Debian系统上的视频网关软件，需要使用升级包和安装脚本。

查看系统版本：

cat /etc/os-release

执行升级命令：

sudo su root
chmod +x install_gateway.sh
./install_gateway.sh
升级完成后，账号 admin 初始密码为 123456，请立即修改为 SPwg@a1b2c3!

2.8 组织树导入

通过Web管理界面导入组织树结构数据，用于管理摄像头资源的层级关系。

2.9 网络配置

配置设备的网络参数，包括IP地址、子网掩码、网关、DNS等。确保设备能够正常访问上级平台和网络。

# 查看网络配置
ip addr show
ip route show

# 编辑网络配置文件
sudo nano /etc/network/interfaces

2.10 存储空间分配

使用GParted工具对磁盘分区进行扩容操作，以获得更多的可用存储空间。

分区扩容步骤：

  1. 打开GParted工具
  2. 选择需要扩容的分区
  3. 调整分区大小
  4. 应用所有操作

安装必要的系统组件：

# 安装语言包和字体
sudo dpkg -i locales_*.deb
sudo dpkg -i fonts_*.deb

# 配置中文环境
sudo dpkg-reconfigure locales

3.3 CentOS7系统

3.3.1 CentOS7忘记开机密码

如果忘记了CentOS 7的开机密码，可以通过以下步骤重置：

  1. 重启设备，在GRUB引导界面按 e 进入编辑模式
  2. 找到 linux16 行，将 ro 改为 rw init=/bin/sh
  3. 按 Ctrl+X 启动
  4. 进入单用户模式后执行 passwd 修改密码
  5. 执行 touch /.autorelabel (SELinux相关)
  6. 执行 exec /sbin/init 或 reboot -f 重启

3.3.2 路由处理

配置CentOS 7的路由规则，确保设备能够正确访问内外网络。

# 查看路由表
ip route show

# 添加静态路由
sudo ip route add 10.0.0.0/24 via 192.168.1.1

# 永久添加路由（编辑配置文件）
sudo vi /etc/sysconfig/network-scripts/route-eth0

3.3.3 安装向日葵

在CentOS 7上安装向日葵远程控制软件，方便远程维护。

# 下载向日葵安装包
wget https://sunlogin.oray.com/download/linux?id=2 -O sunlogin.rpm

# 安装
sudo rpm -ivh sunlogin.rpm

# 启动服务
sudo systemctl start sunloginclient
sudo systemctl enable sunloginclient

6. 摄像头

摄像头的配置、接入和管理。

6.1 视频编码标准

常见的视频编码标准：

  • H.264/AVC：最广泛使用的视频编码标准，兼容性好，压缩率适中。大部分摄像头和播放设备都支持。
  • H.265/HEVC：新一代视频编码标准，在相同画质下比H.264节省约50%的带宽和存储空间。但兼容性相对较低，部分老旧设备可能不支持。
建议在有兼容性要求时使用H.264编码，在带宽或存储有限时使用H.265编码。

6.2 获取海康平台的AKSK

从海康运管中心获取Access Key(AK)和Secret Key(SK)。

获取步骤：

  1. 登录海康运管中心
  2. 进入开发者设置/密钥管理页面
  3. 创建或查看AK/SK密钥对
  4. 妥善保存密钥信息

6.3 海康寻找IP

使用海康工具搜索局域网内海康摄像头的IP地址。

6.4 视频接入四种方式

视频网关支持四种摄像头接入方式：

6.4.1 方式一：GB28181

通过国标GB28181协议接入摄像头，适合大规模、跨平台的视频联网。

  • 上级域IP：由上级平台提供
  • 上级域ID：34020000002000000001
  • SIP服务端口：9703

6.4.2 方式二：ONVIF

通过ONVIF协议接入摄像头，适用于支持ONVIF标准的大部分品牌摄像头。

6.4.3 方式三：RTSP

通过RTSP协议直接拉取摄像头的视频流。

常见品牌RTSP地址格式：

# 宇视(Uniview)
rtsp://用户名:密码@IP地址/video1

# 海康(Hikvision)
rtsp://用户名:密码@IP地址/Streaming/Channels/101

# 大华(Dahua)
rtsp://用户名:密码@IP地址/cam/realmonitor?channel=1&subtype=0

6.4.4 方式四：嵌入式

嵌入式接入方式，将摄像头SDK嵌入到网关系统中。

6.5 摄像头添加

在视频网关Web管理界面中添加摄像头的操作步骤。

6.6 摄像头播放

摄像头无法播放时的排查步骤：

  1. 检查是否离线：在设备列表中确认摄像头状态是否为在线
  2. 检查编码格式：确认摄像头的编码格式(H.264/H.265)是否被网关支持
  3. 检查子码流：如主码流无法播放，可尝试切换到子码流
  4. 检查网络连通性：确认网关能访问摄像头的IP地址
  5. 检查协议配置：确认接入方式(GB28181/ONVIF/RTSP/嵌入式)配置正确
